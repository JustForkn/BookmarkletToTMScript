Turn a bookmarklet into a userscript

Paste a bookmarklet's code below. It gets wrapped as a full Tampermonkey userscript — name, author, icon, match rules, permissions, all of it — configured to fire on its own, same as clicking the bookmarklet.

1 Get the bookmarklet's code

Chrome and Edge block reading a javascript: link's real contents through drag-and-drop — a security measure, not something a page can work around. Open your bookmarks manager, right-click the bookmarklet → Edit, and copy the text from the URL field. Paste it below.
